① 텔레그램 알림 연결 (처음 한 번만)

  1. 텔레그램에서 @BotFather를 찾아 대화를 열고 /newbot 을 보내요.
  2. 봇 이름(예: 사찰순례 알림)과 아이디(끝이 bot, 예: temple_report_bot)를 정하면 토큰(긴 글자)을 줘요. 토큰은 다른 사람에게 보여 주지 마세요.
  3. Supabase → Edge Functions → Secrets 에서 이름 TELEGRAM_BOT_TOKEN, 값에 토큰을 붙여 넣고 저장해요.
  4. 방금 만든 봇과 대화를 열고 /start 를 보내요.
  5. 아래 연결 확인을 누르면 봇이 "알림이 연결되었어요"라고 답해요.

② 텔레그램 코드로 로그인

연결된 텔레그램으로 6자리 코드를 보내 드려요. 비밀번호는 필요 없어요.

🪷 스님 인증 · 초대 코드

스님께 드릴 코드를 만들어요. 스님이 절로에서 👥 함께 순례 → "스님이신가요? 인증 코드 넣기"에 넣으면 그 기기가 금빛 이름표 "🪷 ○○사 ○○ 스님"과 가사를 두른 모습으로 보여요. 코드는 14일 안에 한 번만 쓸 수 있고, 이름에 '스님'을 적은 다른 사람은 스님으로 보이지 않아요.
